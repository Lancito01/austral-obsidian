# Diccionarios
```python
dict.keys() # [key, key, key, ...]
dict.values() # [value, value, value, ...]
dict.items() -> dict_items # [(key, value), (key, value), (key, value), ...]
dict.clear() # Elimina todo el diccionario
len(dict) # Cantidad de pares key-value en el diccionario
list(dict) # Devuelte una lista con solo las claves del diccionario
```
