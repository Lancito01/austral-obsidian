# Calcular Matriz Inversa
Para calcular la inversa de una matriz, se crea un sistema de matriz ampliado con la Matriz que conocemos en la izquierda y la matriz identidad $I$ a la derecha. Intercambiando filas, sumando filas (como se hace para resolver sistemas de matrices), multiplicando filas, etc se tiene que lograr conseguir la matriz identidad $I$ del lado izquierdo, y cuando se llegue a este resultado la matriz resultante en el lado derecho va a ser la inversa a la matriz original.
